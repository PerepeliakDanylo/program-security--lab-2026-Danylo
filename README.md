# RDR2 Dynamic Reload

Набір інструментів, який робить перезарядку зброї в Red Dead Redemption 2 повільною
та реалістичною поза боєм і швидкою під час перестрілки. Тільки одиночна гра.

## Складові

| Компонент | Технологія | Призначення |
|---|---|---|
| `tools/ymt_tweaker` | Python 3, стандартна бібліотека | офлайн-препроцесор метафайлу `weapons.ymt`: задає «повільний» профіль перезарядки |
| `src/` → `DynamicReloadSpeed.asi` | C++17, x64, ScriptHookRDR2 | рантайм-плагін: перемикає профілі перезарядки залежно від того, чи триває бій |
| `dist/` | INI + пресети + README для гравця | те, що потрапляє в релізний архів |
| `tools/drs_release` | Python 3, `cryptography` | офлайн-інструмент супроводжувача: автентифікація, доступ, підпис і паспорт релізу (ЛР4–ЛР8) |
| `tools/drs_hub` | Python 3, `http.server` + `ssl`, `cryptography` | службовий HTTPS-сервер супроводжувача й клієнт: реєстр релізів, з ЛР13 — звіти тестерів (ЛР10+); у реліз мода не входить |
| `tools/release` | Python 3, стандартна бібліотека + `git` | перевірка готовності й відтворювана збірка релізу інструментів супроводжувача (ЛР16) |

## Чому два компоненти

`weapons.ymt` зчитується грою один раз під час завантаження, тому змінювати файл у рантаймі
марно. Файл задає базовий стан, плагін перемикає значення вже у структурах в оперативній пам'яті.

Є й друга причина, сильніша: п'ять стволів — «Ле-Ма», «Флотський», M1899, «Еванс» і слонобій —
узагалі не мають запису `CWeaponInfo` у `weapons.ymt`. Перевірено і на стокових даних гри,
і на злитому файлі оверхолів. Жодна правка файлу їх не дістане.

## Межі проєкту

Проєкт змінює щонайбільше три параметри перезарядки — `AnimReloadRate`, `LoopRate`,
`TimeBetweenBulletsInLoop` (плагін 1.2 за замовчуванням — лише перший) — і не торкається шкоди,
віддачі, розкиду та місткості зброї.
У плагіні й препроцесорі немає мережевої взаємодії, телеметрії та збору даних; службовий сервер
супроводжувача `tools/drs_hub` у реліз мода не входить і з грою не з'єднується. У мультиплеєрі плагін вимикає себе.

**Відоме обмеження, яке не ховається:** `CWeaponInfo` — глобальні дані гри, тому зміна темпу
перезарядки діє й на NPC, а не лише на гравця. Механізму «тільки для одного педа» не знайдено.

## Звідки завантажувати

Гравцям — лише зі сторінки мода на NexusMods. Речення нижче подано **англійською навмисно**: це
дослівна цитата з `dist/README.txt` і з першого екрана сторінки мода — див. виноску під ним.

Canonical download source: the Dynamic Reload Speed mod page on NexusMods (author RedziYT).
Files obtained from any other source are not supported.

*(Речення навмисно дослівно збігається з `dist/README.txt` і першим екраном сторінки мода —
вимога SR-02. Цей репозиторій — вихідний код і запис кожного релізу: тег `v<версія>`, хеш коміту
та SHA-256 архіву й `.asi` у [`docs/changelog.md`](docs/changelog.md) (SR-01, SR-03); окремим
каналом завантаження для гравця він не є.)*

GitHub Releases цього репозиторію (теги `tools-v<версія>`) містять лише інструменти супроводжувача
(`tools/drs_release`, `tools/drs_hub`), а не мод — див. [`SECURITY.md`](SECURITY.md).

## Збірка

Потрібні Visual Studio 2022 Build Tools (C++), Windows SDK, CMake 3.21+ і **ScriptHookRDR2 SDK**,
який у цей репозиторій не входить. Покрокова інструкція — у [`docs/BUILD.md`](docs/BUILD.md).

```powershell
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```
