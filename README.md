# RDR2 Dynamic Reload

Набір інструментів, який робить перезарядку зброї в Red Dead Redemption 2 повільною
та реалістичною поза боєм і швидкою під час перестрілки. Тільки одиночна гра.

## Складові

| Компонент | Технологія | Призначення |
|---|---|---|
| `tools/ymt_tweaker` | Python 3 | офлайн-препроцесор метафайлу `weapons.ymt`: задає «повільний» профіль перезарядки |
| `src/` (`DynamicReloadSpeed.asi`) | C++17, ScriptHookRDR2 | рантайм-плагін: перемикає профілі перезарядки залежно від того, чи триває бій |

## Чому два компоненти

`weapons.ymt` зчитується грою один раз під час завантаження, тому змінювати файл у рантаймі
марно. Файл задає базовий стан, плагін перемикає значення вже у структурах в оперативній пам'яті.

## Межі проєкту

Проєкт змінює рівно три параметри перезарядки і не торкається шкоди, віддачі, розкиду
та місткості зброї. Мережевої взаємодії, телеметрії та збору даних немає.
У мультиплеєрі плагін вимикає себе.
