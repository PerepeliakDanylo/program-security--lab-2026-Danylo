# RDR2 Dynamic Reload

Набір інструментів, який робить перезарядку зброї в Red Dead Redemption 2 повільною
та реалістичною поза боєм і швидкою під час перестрілки. Тільки одиночна гра.

## Складові

| Компонент | Технологія | Призначення |
|---|---|---|
| `tools/ymt_tweaker` | Python 3, стандартна бібліотека | офлайн-препроцесор метафайлу `weapons.ymt`: задає «повільний» профіль перезарядки |
| `src/` → `DynamicReloadSpeed.asi` | C++17, x64, ScriptHookRDR2 | рантайм-плагін: перемикає профілі перезарядки залежно від того, чи триває бій |
| `dist/` | INI + пресети + README для гравця | те, що потрапляє в релізний архів |

## Чому два компоненти

`weapons.ymt` зчитується грою один раз під час завантаження, тому змінювати файл у рантаймі
марно. Файл задає базовий стан, плагін перемикає значення вже у структурах в оперативній пам'яті.

Є й друга причина, сильніша: п'ять стволів — «Ле-Ма», «Флотський», M1899, «Еванс» і слонобій —
узагалі не мають запису `CWeaponInfo` у `weapons.ymt`. Перевірено і на стокових даних гри,
і на злитому файлі оверхолів. Жодна правка файлу їх не дістане.

## Межі проєкту

Проєкт змінює щонайбільше три параметри перезарядки — `AnimReloadRate`, `LoopRate`,
`TimeBetweenBulletsInLoop` (плагін 1.2 за замовчуванням — лише перший) — і не торкається шкоди,
віддачі, розкиду та місткості зброї.
Мережевої взаємодії, телеметрії та збору даних немає. У мультиплеєрі плагін вимикає себе.

**Відоме обмеження, яке не ховається:** `CWeaponInfo` — глобальні дані гри, тому зміна темпу
перезарядки діє й на NPC, а не лише на гравця. Механізму «тільки для одного педа» не знайдено.

## Звідки завантажувати

Наведений нижче блок подано **англійською навмисно**: це дослівна цитата з `dist/README.txt`
і зі сторінки мода, а не недогляд перекладу — див. виноску під ним.

There are exactly two canonical sources:

- the mod page on NexusMods (author RedziYT)
- the Releases section of the GitHub repository
  PerepeliakDanylo/program-security--lab-2026-Danylo

A file obtained from any other source is not supported by this project.

*(Формулювання навмисно дослівно збігається з `dist/README.txt` і першим екраном сторінки мода —
вимога SR-02: перелік джерел має бути однаковим у всіх трьох місцях, інакше його можна
непомітно підмінити в одному з них.)*

## Збірка

Потрібні Visual Studio 2022 Build Tools (C++), Windows SDK, CMake 3.21+ і **ScriptHookRDR2 SDK**,
який у цей репозиторій не входить. Покрокова інструкція — у [`docs/BUILD.md`](docs/BUILD.md).

```powershell
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```
